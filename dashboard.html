    About & Model

    What's real, what's a placeholder, and the honest numbers behind this prototype — CSI1006 Mini Project, Review-2.

    What this is

    ALT models each student as a data-driven "digital twin" built from six behavioural and academic signals — attendance, marks, study hours, assignment completion, daily check-in mood, and sleep. Two real, trained scikit-learn models turn those signals into a GPA forecast and an academic-risk flag; a recommendation layer (Gemini-first, rule-based fallback) turns the forecast into guidance. Access is role-based: an admin (faculty) account sees the whole cohort, a student account only ever sees its own twin — enforced by the backend on every request, not just hidden in the UI.

    Honest about what's real

    Real: the dataset generation, both trained models and their reported metrics, the FastAPI backend, the login system (bcrypt-hashed passwords, signed JWT session tokens, per-request server-side authorization — see auth.py), the Gemini integration code (recommendation + chat endpoints), and this dashboard — all running live, not screenshots.

    Placeholder / in progress: the frontend is HTML/JS rather than the planned React + Tailwind CSS; there's no PostgreSQL database yet (the CSV and a flat users.json are the store); no cloud deployment (Vercel/Render) yet. The login system is real hashing + real signature verification + real per-request checks, appropriately scoped for a course prototype — not hardened for production use with real student records.
